## 2. Fair-value model (pre-registered, no tuning after runs start)
**Model: normal-diffusion terminal-average (v1, "P3-FV1").**
Payoff = P(BRTI-60s-avg ≥ strike). Under driftless Brownian motion of the
index level with per-second vol σ:

- f = Φ((I_t − strike) / σ_eff), Φ = standard normal CDF.
- σ_eff = σ·√(τ − 40) for τ ≥ 60 s; σ_eff = σ·τ^1.5/(60√3) for τ < 60 s,
  where τ = seconds to boundary Te. (Derived: Var of the 60 s average =
  σ²(τ−40) when the averaging window hasn't started; σ²τ³/10800 once inside it.)
- I_t = index feed level at tick t (BTC USD).
- σ = trailing-900 s realized per-second vol of the feed (log-returns,
  ddof=1, floored at $0.25/s so σ_eff never collapses to zero).

**Inputs:** index level + short-horizon vol + strike + time-to-boundary. No
order-book features, no cross-venue features in v1 (deliberately: the test is
whether dumb-fair + buffer + rebate survives adverse selection).

**Known limitations (accepted, not fixed mid-test):** the venue 1s series is a
*proxy* for BRTI (P1: median $4.20 off the settlement stream); any level bias
between proxy and BRTI shifts f but shifts both quotes symmetrically. A bias
term is a named follow-up, not a mid-test patch.

## 3. Quoting rule (pre-registered)
At each book snapshot tick t in the quoting zone (see §6):
1. Compute f, and skew = 0.005 × inv_net (inv_net = signed resting inventory,
   long positive; 0.5¢ per contract mean-reversion).
2. **Bid Up** (buy Up as maker) at `best_bid_up` **iff**
   `best_bid_up ≤ (f − b − skew)` and book non-empty and state OPEN.
   Else no bid this tick.
3. **Offer Up** (sell Up as maker) at `best_ask_up` **iff**
   `best_ask_up ≥ (f + b − skew)`. Else no offer this tick.
4. b (adverse-selection spread buffer) = **0.03 (3¢) flat, both sides**.
5. Quote size q = **2 contracts** per side per tick. One price level per side
   (the touch only). Cancel/replace every snapshot (standing quote = last tick's).
6. Never cross: if a computed quote would cross the touch, that side is pulled.
   Maker-only by construction — the shadow never takes, so taker fees = 0.

Rationale for "join touch subject to buffer" (not "rest at f±b inside the book"):
resting at f−b when the touch is better (e.g. bid 40¢, f−b 47¢) would make us
the best bid with zero edge — pure adverse-selection donation. We only provide
liquidity when the touch pays us ≥ b vs fair. Queue-jumping (1¢ inside touch)
is a named follow-up variant, not v1.

## 5. Fill model — shadow fill counts ONLY if the book traded through our resting price (Q6 rule)
Per (Up-contract) print record, processed in time order between snapshots:
- Standing **bid** at pb, size q. Let depth(pb) = resting size at pb on the
  latest book BEFORE the print.
  - print_px < pb → traded through → **full fill q** (queue position irrelevant).
  - print_px == pb → fill = min(q, max(0, delta_shares − depth(pb)))
    (last-in-queue: we are behind the entire displayed level).
  - print_px > pb → no fill.
- Standing **offer** at pa, size q:
  - print_px > pa → traded through → full fill q.
  - print_px == pa → fill = min(q, max(0, delta_shares − depth(pa))).
  - print_px < pa → no fill.
- Prints are 2 s aggregates; `print_px` is the LAST fill price, not VWAP —
  the at-price branch is therefore conservative by construction. No fill is
  ever inferred from book movement alone.

## 6. Inventory, pull, quoting zone (pre-registered)
- **Inventory cap:** |net| ≤ **4 contracts per window** (net across both sides;
  long positive). Worst-case single-window loss bound ≈ 4 × $1.02 ≈ **$4.08**.
- **Paper bankroll (shadow desk):** B0 = **$100**, separate from Satoshi's paper
  bankroll, no shared state. Kill-limit analog = 10% of peak = $10.
  Conservative fraction = **50% of the kill limit = $5.00 per window**.
  $4.08 ≤ $5.00 ✓ (sizing scales with bankroll; the test proves the edge, not the size).
- **Pull rule:** cancel all quotes (no new quotes) when τ < **N = 120 s**.
  N = 120 pre-registered: the last 60 s is the averaging window (peak adverse
  selection; P3-alt's territory, not ours) plus a 60 s safety margin for
  settlement freeze and stale prints. Also pull on: state ≠ OPEN, empty book,
  crossed book (best_bid ≥ best_ask), poll gap > 15 s, or quotes would cross.
- **Quoting zone:** τ ∈ [120 s, 870 s] (start 30 s after window open so the book
  forms; stop 120 s before boundary).
- **No position carried across the boundary:** binaries expire; whatever net
  inventory exists at pull time rides to settlement inside the cap. No
  flattening (maker-only; crossing to flatten would pay taker fees and is out
  of scope for v1).

## 7. Fee model (pre-registered)
- θ_maker, θ_taker read per book record from its `fee` block (`fee_src` stamped);
  fallback `research/fee_cache.json`; re-read cadence inherits the recorder's
  ~5 min refresh. **Never hardcoded.**
- Per fill event: maker_fee = banker's_round(θ_maker × C × p × (1−p)).
  Rebate (θ_maker < 0) credited at point of trade, tracked as its own column.
- **Two P&L columns per window:**
  - `net_conservative` = gross + maker_fee(θ_maker := 0)  ← **acceptance column**
    (Tier-1 post-Oct-19 view: NO rebate).
  - `net_regime` = gross + maker_fee(θ_maker from record) ← reported, not decision-bearing.
- Taker fees = 0 by construction (never cross). Documented, not assumed: any
  engine path that could cross is a fail-closed pull instead.

## 8. Acceptance criteria (EXACT)
1. **Net P&L after adverse selection > 0 with 95% CI excluding 0 over ≥300
   windows** — operationalized: mean per-window `net_conservative` > 0 with a
   window-level bootstrap 95% CI (10,000 resamples) that excludes 0.
2. **Worst single-window inventory loss inside kill limits** — operationalized:
   min over windows of `net_conservative` ≥ −$5.00 (the conservative fraction
   from §6), i.e. one full adverse window cannot breach half the 10%-of-peak
   drawdown analog.
3. Usable-window definition (§9) applies to both.

## 9. Usable window (pre-registered)
A window counts toward the ≥300 iff ALL hold:
- strike available (StrikeProvider hit);
- outcome available (OutcomeProvider hit);
- ≥50% of expected book snapshots present inside the quoting zone
  (expected = zone_seconds / 3);
- no recorder gap > 60 s inside the quoting zone;
- ≥1 quote tick evaluated (book non-empty, state OPEN at least once in zone).
Windows failing coverage count toward fill-rate stats only.

## 10. Falsification conditions (what a clean fail looks like)
- **FAIL (no edge):** ≥300 usable windows AND (mean net_conservative ≤ 0
  OR bootstrap 95% CI includes ≤ 0).
- **FAIL (risk):** any single window net_conservative < −$5.00.
- **INCONCLUSIVE (underpowered, not a fail):** ≥300 usable windows but
  < 0.5 fills/window on average — the quoting rule never engaged; parameterize
  (b, q, touch-join vs queue-jump) and re-test.
- **Conditional pass (not acceptance):** conservative fails but regime-with-rebate
  passes → reported as rebate-dependent, does NOT satisfy criterion 1.
- A thin-data "pass" (< 300 usable windows) is **not a pass** — verdict stays
  UNPROVEN until 300.
